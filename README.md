# 🏠 House Price Prediction Web Application

This project is a machine learning–based web application that predicts house prices based on property features.  
It uses a trained regression model deployed with FastAPI and a simple HTML/JavaScript frontend.

## 📌 Features

- Predicts house prices using machine learning
- User-friendly web interface
- REST API built with FastAPI
- Deployed on cloud platforms
- Uses real housing dataset
- Includes feature engineering and preprocessing

## ⚙️ Machine Learning Workflow

1. Data Cleaning and Encoding
2. Feature Engineering
3. Feature Scaling (StandardScaler)
4. Log Transformation of Target Variable
5. Model Training (Linear Regression)
6. Model Evaluation (RMSE, R²)
7. Model Serialization (Joblib)
